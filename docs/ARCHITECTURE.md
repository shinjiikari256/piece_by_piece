# Архитектура: офлайн и онлайн

Справка по тому, как игра доставляется и где что проверяется. Подробности по файлам — в `CLAUDE.md`.

## Две сборки одной игры

| | Офлайн-файл | Онлайн-версия |
|---|---|---|
| Что это | один `.html`, открывается без сети | сайт на сервере вуза |
| Дела | выбранный набор вшит **вместе с ответами** | приходят **без ответов** (`PublicCase`) |
| Проверка | в браузере (`LocalAuthority`) | на сервере (`ApiAuthority`) |
| Результаты | на экране + файл результата | у преподавателя поимённо |

- Файл с ответами — для тренировки, не для контроля. Гость на онлайн-сайте играет на `LocalAuthority`, поэтому JSON дел остаётся в клиентском бандле; убрать его можно, только если гостю тоже играть через сервер (анонимные попытки).
- Офлайн: `pnpm export:offline`; ключи localStorage с идентификатором сборки (`offline:<buildId>:`). Файл результата: версия формата/игры/дела, игрок, итог и `input`; сервер принимает его импортом с пересчётом.

## Судья и платформа

- Клиент работает через `CaseAuthority` (`shared/judge.ts`): `checkDeduction`, `revealHint`, `restore`, `finish`, `debrief`. Игра видит только `PublicCase` (`toPublicCase`); подсчёт баллов — общий код в `shared/`.
- Всё, что зависит от среды, идёт через `GamePlatform` (`state/platform.ts`): сохранения и результаты, асинхронно. Подключается один раз в `main.tsx`: `browser-platform` (`localStorage`), `online-platform` (оболочка над ней: сохранения вошедшего ещё и на сервере, запись локально сразу, на сервер с задержкой 3 с и при паузе/закрытии; читается более свежая копия по `savedAt`), `memory-platform` (тесты). Ядро (`store`, `autosave`, `scene-host`) не импортирует хранилище браузера и учётную запись.
- Попытка — единица учёта на сервере (`attempts`): время, подсказки и ошибки считает она, результат пишет только `/finish`. Защита от подделки опирается на серверное время, лимит проверок, порядок подсказок и версию дела. Не проверяется, что игрок добыл улики, которыми отвечает (см. «Игровая машина на сервере» в `BACKLOG.md`).

## Роли и данные
- Администратор — всё; преподаватель — свои группы и студентов без группы; студент — свои прохождения. Регистрация со ссылкой группы (автоподтверждение — настройка ссылки).
- Таблицы — `apps/server/src/db/schema.ts` (пользователи, сессии, группы, ссылки, дела и версии, мероприятия, попытки, события попыток, сохранения, результаты, `audit_log`, `rate_hits`). Миграции применяются при старте API и должны быть только аддитивными (откат образа без отката схемы).
- Персональные данные (152-ФЗ): хранить на серверах в РФ, минимум данных (логин, ФИО, группа), согласие с версией текста и временем, срок хранения и порядок удаления — решает юрист (см. «Перед запуском» в `README.md`).

## Нерешённые вопросы платформы
- Неотправленный результат: повторная отправка при входе — на платформе или в ядре? Сейчас остаётся в браузере и показывается тост.
- `navigate` из `ui/lib/router` в `store.ts`: оставить в ядре или вынести в интерфейс «хоста».
- Подписка на изменения из другой вкладки или перечитывание при открытии экрана.
